# Mini projet : Suivi et analyse de la consommation énergétique

## Description
Ce projet simule un dispositif de suivi et d’analyse de la consommation énergétique.  
Il repose sur la **programmation orientée objet** et utilise **MongoDB** pour stocker les données.  

Fonctionnalités principales :  
- Simulation de capteurs IoT générant des mesures aléatoires.  
- Stockage des mesures dans MongoDB.  
- Détection automatique des anomalies de consommation.  
- Maintien de la qualité du code avec **Pytest** et **flake8**.  

**Remarque :** aucune interface graphique ni communication IoT réelle n’est utilisée.

---

## Objectifs
- Mettre en place une architecture orientée objet (POO).  
- Simuler et gérer des capteurs IoT.  
- Stocker et manipuler les données dans MongoDB.  
- Détecter les anomalies de consommation.  
- Assurer la qualité du code via tests unitaires et flake8.
